One-time setup

Activate the backend

You're signed in, but the database tables don't exist yet. Install the schema once and everything switches on.

  1. Open the SQL editor — Supabase dashboard → SQL Editor
  2. Paste & run the contents of supabase/install.sql from the GitHub repo (creates tables, security rules, the image bucket and seeds the current website content).
  3. Create your login — Authentication → Users → Add user (tick Auto Confirm User).
  4. Come back here and re-check — then claim admin access.
